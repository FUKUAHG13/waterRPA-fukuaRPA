fukuaRPA 是一款 Windows 桌面可视化自动化工具。通过添加步骤、选择动作、取点或框选图片，就能把点击、按键、识图、等待、判断和循环组合成自己的自动流程。

它基于 waterRPA 持续重构与增强，适合重复点击、固定界面操作、周期检查和桌面流程复现，也支持变量、表达式、窗口操作、计划任务与插件扩展。

## 下载后，三步开始

1. 前往 [下载页面](https://github.com/FUKUAHG13/waterRPA-fukuaRPA/releases/latest)，选择多文件版或单文件版。
2. 多文件版完整解压后运行其中的 EXE；单文件版直接运行。两种版本都包含运行环境，无需另外安装 Python。
3. 添加几个步骤，取点或框选目标图片，设置启动和停止热键，先跑通一个小流程。

| 版本 | 适合谁 |
|---|---|
| **多文件版 `portable.zip`（推荐）** | 日常使用。完整解压后运行，启动更直接，也方便查看文件。 |
| **单文件版 `single.exe`** | 希望只携带一个 EXE。启动时需要释放内置运行文件。 |

支持 **Windows 10 1809 及以上 x64、Windows 11 x64**。**Windows 10 当前版本未经测试。**

## 从简单操作到完整流程

### 新手用简易模式，熟悉后切换高级模式

简易模式集中展示常用动作和必要参数，方便快速搭出第一套流程；高级模式展开识别细节、条件处理、执行策略和调试设置。同一套软件，按需要选择操作深度。

步骤可以复制、排序、分组、备注、标色和临时禁用；较长流程还可以用断点与单步调试逐步检查。

### 找到目标，再执行动作

- **图片识别**：支持缩放匹配、灰度、反色、透明遮罩、忽略变化区域和图片内指定点击位置。
- **多区域、多目标**：只搜索需要的位置；找到多个目标后，按位置或距离安排点击顺序。
- **坐标与路径**：直接取点、自定义多个点位，或根据起点、终点和数量生成等距路径；运行前预览坐标，并拖动修正。
- **条件等待**：等待图片出现、消失或区域变化，再继续后续步骤。

### 让步骤之间有判断、有配合

- 点击、双击、拖拽、悬停、滚轮、按键、等待、截图和提醒等常用动作。
- 有限次数、指定时间或持续循环，配合成功、失败、重试、超时和跳转处理。
- 变量与表达式，让不同步骤传递数据、判断条件。
- 启动程序、等待或激活窗口；对兼容的程序使用 Windows UI Automation（UIA）点击控件、设置文本和读取文本。

### 录制、快捷工具和定时执行

| 能力 | 用途 |
|---|---|
| **键鼠录制与回放** | 保留实际采集到的按住、重复、重叠和拖拽时序，减少逐步配置的工作。 |
| **独立连点器** | 设置点击位置、按钮、间隔、次数和启停热键。 |
| **按键映射** | 把字母、数字、功能键或组合键绑定为指定位置的点击。 |
| **多方案快捷启动** | 为常用方案设置启动热键，减少来回切换。 |
| **计划任务** | 按时间或周期触发方案，查看运行记录、错过执行及冲突处理结果。 |
| **插件中心** | 按需扩展浏览器自动化、本地 OCR、办公文档和屏幕录制等能力；具体依赖见各插件说明。 |

## 方案能保存，也能带走

- **普通导出**：保存步骤与设置为 JSON，不复制模板图片，适合同一台电脑备份。
- **完整迁移包**：将方案和引用图片一起打包，方便迁移到自己的其他电脑；首次导出会提醒其中可能含有私人内容。
- **脱敏分享包**：移除敏感流程内容和模板图片，并停用受影响步骤，便于分享流程结构或协助排查问题。

凭据库中的秘密值不随方案导出。浅色、深色主题和界面缩放也可以按使用习惯调整。

## 本地运行，兼顾响应速度

原生识别核心、模板与截图复用、自适应等待、按需加载和高频界面更新合并，减少重复计算与集中加载。原生识别不可用或不适合当前任务时，保留 Python/OpenCV 回退路径。实际效果取决于硬件、目标画面和流程配置。

**fukuaRPA 本身不访问互联网或局域网，不发送遥测、不自动检查更新，也不上传操作数据。** 方案、图片与运行日志保存在本地。

运行日志默认启用隐私保护；用户可在本机主动关闭该保护用于调试。凭据值和“输入秘密文本”的原文始终不进入日志，诊断与崩溃报告也继续脱敏。

## 使用前了解这几件事

- 计划任务需要主程序保持运行，并有可用的桌面会话；不支持关机或无人登录时自动操作桌面。
- UIA、后台点击和模拟输入的适用性取决于目标程序，不保证所有应用、游戏或高权限窗口都能响应。
- 识图会受到缩放、主题、动画和截图质量影响，建议使用特征清晰的目标图片。
- 录制回放以实际采集到的事件为准，不承诺逐点、毫秒级还原，也不包含 IME 组字和跨应用焦点切换的完整还原。
- 升级前先备份方案、配置和图片，不承诺所有旧版方案直接兼容。

## 开源与继续开发

项目源码采用 **MIT 许可证**，可以查看、修改和继续开发。普通用户直接下载成品包即可；开发者可从源码运行。

<details>
<summary>从源码运行</summary>

环境：Windows x64、CPython 3.14.3 x64。

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe fukuaRPA.py
```

可选原生识别核心需要 Visual Studio 2022 Build Tools 的 C++ 工具链与 Windows SDK：

```powershell
powershell -ExecutionPolicy Bypass -File native_core/build_native_core.ps1
```

未构建原生核心时，仍可使用 Python/OpenCV 路径。公开仓库不包含部分内部设计与验证材料；运行主程序不依赖这些资料，完整维护者发布验证需要相应私有输入。

</details>
